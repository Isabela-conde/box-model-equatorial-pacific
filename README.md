# toy_model_surface_wind_flux_increase

A toy model exploring the response to an increase in surface wind / heat flux, based on a Zebiak–Cane-style setup.

## What's here

- `toy_model/` — the model code:
  - `toy_model.jl` — core model.
  - `run_toy_model.jl` — driver script to run an experiment.
  - `toy_plots.jl` — plotting helpers.
  - `testing.jl` — scratch tests.
- `runs/` — output from individual runs (timestamped). **Not tracked in git** — regenerated by running the model.
- `initial_code_videos/` — animations from early runs.

## How to run

```julia
] activate .
] instantiate
include("toy_model/run_toy_model.jl")
```

## Note on data

Large model output (`.jld2` files, the `runs/` outputs, videos, `.png` figures) is excluded from git via `.gitignore` to keep the repository small. Only the code and this README are version-controlled. If you need to share specific output, add it deliberately.
