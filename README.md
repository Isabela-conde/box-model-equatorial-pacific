# toy_model_surface_wind_flux_increase

This is a toy model was based on an oceananigans.jl example https://clima.github.io/OceananigansDocumentation/stable/literated/ocean_wind_mixing_and_convection. We use a hydrostatic model of the tropical Pacific as a box mdoelled on approximatly 10N--10S, using a beta plane approximation. Model detials can be found in `docs/model_description.md`. The model was helped in development by Claude at Anthropic, in particular making the model stable.  
## What's here

- `toy_model/` — the model code:
  - `toy_model.jl` — core model.
  - `run_toy_model.jl` — driver script to run an experiment.
  - `toy_plots.jl` — plotting helpers.
  - `after_run_plots.jl` — scratch tests.
    `docs\model_description.md` - model description.
- `runs/` — output from individual runs (timestamped). **Not tracked in git** — regenerated by running the model.
